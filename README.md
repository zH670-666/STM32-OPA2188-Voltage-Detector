# 基于 OPA2188 与 STM32 的 0-10V 高精度电压信号调理及检测系统

本项目为**物光创新实验室 2026 年招新提交作品**。项目针对工业与传感器采集场景中常见的 0-10V 信号，设计并制作了一套兼具高精度、低漂移特性的信号调理 PCB 板，并联合 STM32 单片机与上位机实现了数据的实时采集、波形可视化与线性校准。

---

## 📌 项目背景与应用场景

在工业自动化与光电测量系统中，许多传感器（如压力、光强、位置传感器）的输出信号范围为 $0 \sim 10\text{V}$。然而，现代单片机（如 STM32F103）的 ADC 输入电压范围通常仅为 $0 \sim 3.3\text{V}$，直接接入会导致芯片烧毁或无法测量。

本项目旨在设计一套**高精度电压衰减与调理电路**，将高压信号转换为单片机安全的采集范围，并通过算法实现电压的线性还原与上位机波形监测。

---

## 🛠️ 硬件与系统架构

### 1. 硬件选型
* **信号调理芯片**：**OPA2188**（低失调电压、Zero-Drift 零漂移运算放大器，确保高精度）
* **微控制器**：**STM32F103C8T6** ("Blue Pill" 核心板)
* **串口通讯模块**：**CH340 USB-TTL 模块**
* **EDA 设计工具**：嘉立创 EDA

### 2. 硬件接线与信号链路
```text
[ 0-10V 输入信号 ] 
       │
       ▼
[ OPA2188 信号调理 PCB ] ──( 0-3.3V 比例信号 )──► [ STM32 PA0 (ADC1_IN0) ]
       │                                                      │
     GND共地                                               USART1 (PA9/PA10)
       │                                                      │
       └──────────────────► [ CH340 模块 ] ◄──────────────────┘
                                   │
                                USB接口
                                   ▼
                            [ 上位机 VOFA+ ]
```

**引脚连接表：**
| 发射/接收端 | 目标端 | 信号说明 |
| :--- | :--- | :--- |
| **OPA2188 PCB VCC/GND** | STM32 3.3V / GND | 调理板供电与共地 |
| **OPA2188 PCB OUT** | STM32 PA0 | 经过比例衰减后的模拟电压 |
| **STM32 PA9 (TX)** | CH340 RXD | 串口数据发送 |
| **STM32 PA10 (RX)** | CH340 TXD | 串口数据接收 |
| **STM32 GND** | CH340 GND | 系统统一共地 |

## 💻 软件设计与算法实现

### 1. 软件流程
1. **ADC 定时采样**：配置 STM32 内部 ADC（12 位分辨率），采样 PA0 模拟电压。
2. **数据均值滤波**：对多次 ADC 采样值进行滤波处理，消除高频噪声。
3. **两点线性校准算法**：
   通过拟合一次函数 $y = k \cdot x + b$ 实现电压校准：
   $$V_{out} = k \cdot V_{adc\_raw} + b$$
4. **数据打包发送**：通过 USART1 将电压计算值组帧发往上位机。

### 2. 上位机交互 (VOFA+)
* **通信协议**：采用 `JustFloat` 浮点数传输协议，实现低延迟波形绘制。
* **波特率**：`115200 bps`

## 🔍 开发、焊接与调试记录 (问题分析与解决)

在项目从原理图转化为实物的过程中，攻克了以下关键硬件与调试问题：

1. **PCB 焊接与静态短路排查**
   * **问题**：初次将 OPA2188 PCB 与 STM32 连接时，发现 STM32 核心板电源指示灯熄灭。
   * **排查与解决**：迅速断电，使用万用表蜂鸣档测试 VCC 与 GND，排查出 PCB 存在微小焊锡连锡导致的供电短路。清理焊点后复测恢复正常。
2. **串口通信异常排查**
   * **问题**：VOFA+ 无法收到数据波形。
   * **排查与解决**：核对硬件链路，确认 CH340 与 STM32 之间保持 **TX/RX 交叉连接**，并且确认了 **系统共地 (GND)** 是串口电平基准一致的前提。
3. **零点校准与测试**
   * 使用短路线将运放板输入端直接短接到 GND（输入 $0\text{V}$），在 VOFA+ 中观察底噪与零点偏置，确保了良好的基准稳定度。
